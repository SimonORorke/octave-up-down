# Octave Up-Down for MIDI Pedals

Octave Up-Down for MIDI Pedals allows a pair or sustain pedals or momentary footswitches to be used instead of the octave shift buttons on a MIDI keyboard to transpose notes and note aftertouch /polyphonic aftertouch / pressure up or down by multiple octaves. A bonus feature allows the control change number of a MIDI controller to be changed:  the controller may be one of the pedals used for octave transposition.
